The main improvement is to replace the fixed-size 2D DP table with two rolling 1D arrays, sized only to the maximum value in `nums`. This reduces memory usage and avoids iterating up to 1000 when the input maximum is smaller. I also compute prefix sums in the same pass and use `int` arithmetic where possible.
