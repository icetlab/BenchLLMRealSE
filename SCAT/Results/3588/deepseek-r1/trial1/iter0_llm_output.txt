The main optimization is to replace the recursive memoized DP and `HashMap`/string-based rule lookup with an iterative DP that uses a fixed 3×3 gain matrix and only two rolling score layers. This reduces memory from `O(n²)` boxed `Integer` states to `O(n)` `int` states and removes autoboxing/string concatenation overhead.
