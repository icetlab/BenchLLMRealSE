We can improve performance by replacing the `TreeSet` and `HashMap` with more efficient data structures. The key insight is that we only need the min and max values of `a` and `b` after removing each point. Instead of using `TreeSet` (O(log n) for add/remove/first/last), we can precompute the top two smallest and largest values for each coordinate, allowing O(1) lookups during the removal loop.
