## Improvement Intent

The previous patch failed because it changed the return type of `findDistances` from `Map<Integer, MyBean>` to `Map<Integer, Long>`, but the DP code still expected `MyBean` objects with a `.distance` field. This caused a compilation/runtime error. The fix is to keep the original `MyBean`-based distance map structure but optimize the DP loop to avoid the infinite loop bug (the original `j <= Math.min(j + 100, ...)` condition) and improve performance by reducing redundant lookups.
