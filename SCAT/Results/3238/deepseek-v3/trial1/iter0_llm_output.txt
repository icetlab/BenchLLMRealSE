## Improvement Intent

The main performance bottlenecks in this code are:
1. **Redundant Dijkstra calls**: Running Dijkstra's algorithm for every vertex in the graph is extremely expensive. Instead, we can run Floyd-Warshall or run Dijkstra once from each unique vertex.
2. **Inefficient inner loop**: The inner loop condition `j <= Math.min(j + 100, source.length() - 1)` is buggy and creates an infinite loop. It should be `j < source.length()` with a proper limit.
3. **Unnecessary object creation**: Creating `MyBean` objects repeatedly in the distance map can be optimized.
4. **Redundant index lookups**: `findIndex` is called multiple times for the same strings.
