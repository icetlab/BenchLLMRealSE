Overall Improvement Intent:
Replace the per-row full sort of all columns with a single linear scan to extract just the top three values (and their column indices) per row. This cuts the O(n log n) sort per row down to O(n), greatly improving performance when n is large, while preserving the existing logic which only ever uses the top three entries in each row.
