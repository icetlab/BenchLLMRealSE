The original solution repeatedly queries a segment tree during binary search, giving roughly O(n log² n) time. I replaced it with a linear scan of the distinct OR values of subarrays ending at each position. Because OR only sets bits, there are at most 32 distinct values per position, so the new solution is O(n · 32) time and uses O(1) extra space.
