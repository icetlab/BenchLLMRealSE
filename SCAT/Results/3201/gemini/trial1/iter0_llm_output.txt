The original solution uses a loop that iterates up to `limit + 1` times, resulting in a time complexity of O(limit). While this is acceptable for small values of `limit`, it can be inefficient for larger inputs.

The problem of distributing `n` identical items to 3 distinct recipients with an upper bound constraint is a classic combinatorial problem. It can be solved more efficiently using a mathematical formula derived from the Principle of Inclusion-Exclusion. This approach calculates the result in constant O(1) time, regardless of the input size.

My improvement replaces the iterative solution with this direct mathematical formula. This involves:
1.  Calculating the total number of ways to distribute `n` candies to 3 children without any limit, which is `C(n + 2, 2)`.
2.  Subtracting the cases where at least one child exceeds the `limit`.
3.  Adding back the cases where at least two children exceed the `limit` (as they were subtracted twice).
4.  Subtracting the cases where all three children exceed the `limit`.

This change significantly improves performance by moving from a linear-time algorithm to a constant-time one. A helper function `combinations(k)` is introduced to compute `C(k, 2)` cleanly.
