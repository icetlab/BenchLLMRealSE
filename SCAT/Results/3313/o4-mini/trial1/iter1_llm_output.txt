We need to avoid overflow when adding to the initial `curr = Long.MIN_VALUE`.  Instead of doing `curr + value` unconditionally (which can underflow and wrap to a huge positive), we should compute  
`curr = Math.max(dp[i-1][j], curr) + value;`  
so that on the first iteration (when `curr` is `Long.MIN_VALUE`) we always use `dp[i-1][j]` as the base.
