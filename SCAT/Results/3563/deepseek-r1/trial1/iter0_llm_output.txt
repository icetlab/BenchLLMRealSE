The original recursion explores many row-assignment branches, which can grow exponentially. I replaced it with a bipartite matching approach: sort unique values in descending order and greedily add a value whenever it can still be matched to a row using an augmenting-path search. This preserves the same result for the intended positive-value problem while drastically reducing runtime.
