**Improvement intent:**  
The original triple‑nested loop runs in O(n³), which is extremely slow for large `n`.  
By iterating only over the first child's candy count (`i`) and computing the number of valid `(j,k)` pairs directly, the complexity is reduced to O(min(limit, n)). This results in a massive speedup while producing identical results.
