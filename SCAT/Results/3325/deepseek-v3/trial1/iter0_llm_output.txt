## Improvement Intent

The main performance bottleneck is in the `maxSquare` method which unnecessarily swaps rectangles and has redundant logic. The key optimization is to directly compute the intersection without swapping, and to use primitive local variables instead of creating temporary Rectangle objects. Additionally, we can avoid the `record` overhead by working directly with the input arrays.
