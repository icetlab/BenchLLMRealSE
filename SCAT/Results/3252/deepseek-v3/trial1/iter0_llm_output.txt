## Improvement Intent

The current solution has O(n³) time complexity due to creating new ArrayLists for every subarray and checking strictly increasing property each time. We can optimize by:
1. Precomputing the longest strictly increasing prefix and suffix arrays to avoid repeated checks
2. Using two-pointer technique to count valid subarrays in O(n²) or better

The key insight: A subarray [i,j] is "incremovable" if the remaining elements (prefix before i and suffix after j) form a strictly increasing sequence. We can precompute the longest increasing prefix ending at each index and longest increasing suffix starting at each index, then use this to quickly verify if removing [i,j] leaves a valid sequence.
