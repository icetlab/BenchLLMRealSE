## Improvement Intent

The main performance bottleneck is in the `check` method which iterates through all subsets of coins (2^n combinations) for each binary search iteration. This is extremely inefficient for large coin arrays. The improvement focuses on:

1. **Optimizing the LCM calculation** by precomputing LCMs for subsets using dynamic programming to avoid redundant calculations
2. **Using long[] arrays instead of recomputing** LCM values for each subset in every check call
3. **Reducing binary search iterations** by using a tighter upper bound based on the minimum coin value
