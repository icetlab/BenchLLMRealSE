The original implementation uses `ArrayList<Double>` for sorted order and binary search, but inserting into an `ArrayList` at an arbitrary index is O(n). For large inputs (e.g., up to 10⁵ elements), this leads to O(n²) runtime. The improvement replaces the sorted `ArrayList` with a Fenwick Tree (Binary Indexed Tree) to query the count of elements greater than the current value in O(log n) per operation, while preserving the original insertion order in two plain `ArrayLists`. Coordinate compression reduces the value range to the array size, making the Fenwick Tree efficient. This preserves the exact decision logic and output order.
