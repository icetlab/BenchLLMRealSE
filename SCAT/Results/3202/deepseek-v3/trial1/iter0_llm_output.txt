## Improvement Intent

The current implementation has several performance issues:
1. **Redundant map operations**: Using `containsKey` followed by `get` performs two lookups instead of one
2. **Unnecessary string parsing**: `Integer.parseInt` is called multiple times for the same values in the inner loop
3. **Unnecessary sorting**: The entire list is sorted even though we only need to check consecutive elements
4. **Debug print statement**: `System.out.println(temp)` adds unnecessary I/O overhead

The optimized version uses `computeIfAbsent` for single-lookup map operations, pre-parses time strings to integers, and removes the debug print statement.
