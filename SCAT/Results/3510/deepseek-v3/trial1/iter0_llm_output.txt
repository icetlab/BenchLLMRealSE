## Improvement Intent

The main performance bottleneck is the custom `mergeSort` implementation, which has high overhead due to recursive calls and temporary array allocations. We can replace it with Java's built-in `Arrays.sort()` which uses a highly optimized Dual-Pivot Quicksort for primitives, providing better performance. Additionally, we can slightly optimize the loop logic by combining the validation and sum calculation into a single pass.
