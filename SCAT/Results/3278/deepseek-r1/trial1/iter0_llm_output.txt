The original code is O(n³) due to a nested loop of pairs and an inner scan for each pair to check if any other point lies inside the rectangle. By compressing coordinates, building a 2D prefix sum array, and using it to count points in the rectangle in O(1), the overall complexity is reduced to O(n²) while preserving correctness.
