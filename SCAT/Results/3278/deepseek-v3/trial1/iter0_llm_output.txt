## Improvement Intent

The original code has O(n³) time complexity due to nested loops and scanning all points for each pair. The main performance bottlenecks are:
1. The `isValidPair` method iterates through all points for every pair, making it O(n³)
2. The sorting by y-coordinate is unnecessary for the current algorithm
3. We can optimize by pre-sorting points and using early termination conditions

The key insight is that for a valid pair (upper-left, lower-right), we need to ensure no other point lies in the rectangle. We can sort points by x-coordinate and use a more efficient checking approach.
