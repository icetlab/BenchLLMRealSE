## Improvement Intent

The previous optimization failed because the bit manipulation logic was incorrect. The correct approach is: for each number `num`, we need to find `ans[i]` such that `ans[i] | (ans[i] + 1) == num`. This is equivalent to finding the rightmost occurrence of "10" in the binary representation and replacing it with "01". If no such pattern exists (e.g., all bits are 1, or the number is 1 or 2), return -1.
