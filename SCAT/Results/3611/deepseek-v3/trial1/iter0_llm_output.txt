## Improvement Intent

The original code has several performance issues:
1. **Redundant string operations**: Converting integers to binary strings and back multiple times
2. **Inefficient bit checking**: Using string characters instead of bitwise operations
3. **Unnecessary loops**: Multiple nested loops that can be simplified
4. **Complex logic**: The algorithm can be replaced with a simple bit manipulation approach

The key insight is that for any number `n`, we need to find `ans[i]` such that `ans[i] | (ans[i] + 1) == nums[i]`. This can be solved by finding the rightmost zero bit in `nums[i]`, setting it to 1, and clearing all bits to its right.
