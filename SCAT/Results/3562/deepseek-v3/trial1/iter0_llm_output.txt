## Improvement Intent

The main performance bottlenecks in this code are:
1. **Excessive string concatenation** for HashMap keys (`i + "*" + k`) creates many temporary strings
2. **Unnecessary list copying and sorting** in the DP solution - we create new lists and sort them even when not needed
3. **Redundant sorting** of result lists multiple times during comparison
4. **Using `ArrayList` copy constructor** which is O(n) and called frequently

The key optimizations:
- Replace string-based HashMap keys with a custom key object to avoid string concatenation
- Avoid unnecessary list copying by only creating copies when actually needed
- Cache the sorted order of intervals to avoid repeated sorting
- Use primitive arrays where possible for better performance
