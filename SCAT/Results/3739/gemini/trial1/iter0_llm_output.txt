The original code calculates the total sum of Manhattan distances between all pairs of points on an `m x n` grid using a nested loop, which has a time complexity of O(m*n). This sum is then multiplied by a combinatorial factor.

The sum of distances between all unordered pairs of points on an `m x n` grid can be expressed with the closed-form formula `m*n*(m+n)*(m*n-1)/6`.

By implementing this formula, we avoid the costly nested loops, reducing the overall complexity from O(m*n) to O(log M) per call. Additionally, a check is added to handle cases where `k` is too large or too small, which also prevents a potential `ArrayIndexOutOfBoundsException` in the original `cnr` logic.
