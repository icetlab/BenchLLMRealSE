The original O(n^2) solution iterates through all possible substrings, which is inefficient for large inputs. My improved solution uses a prefix-sum-based approach combined with a hash map to count the beautiful substrings in a single pass, achieving a much faster O(n + sqrt(k)) time complexity.

A substring `s[i..j]` is beautiful if:
1. The number of vowels equals the number of consonants.
2. `(vowels * consonants) % k == 0`, which simplifies to `vowels^2 % k == 0`.

The first condition is equivalent to `diff[j+1] == diff[i]`, where `diff` is the running count of `vowels - consonants`.
The second condition is more complex. It can be shown that `vowels = (length of substring) / 2 = (j+1 - i) / 2`. The condition `vowels^2 % k == 0` is equivalent to `(j+1 - i)` being a multiple of `2*m`, where `m` is a value derived from the prime factorization of `k`. This check can be performed using modular arithmetic: `(j+1) % (2*m) == i % (2*m)`.

The optimized algorithm iterates through the string, calculating a running `diff`. For each prefix ending at index `p`, we find the number of starting indices `q < p` that satisfy both conditions by looking up the pair `(diff[p], p % (2*m))` in a hash map. This allows us to count all beautiful substrings in linear time relative to the string length.
