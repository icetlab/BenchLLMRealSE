## Improvement Intent

The original solution uses O(n²) time by checking all substrings from each starting position. We can optimize by using a prefix sum approach with a hashmap to track the difference between vowel and consonant counts, similar to the "contiguous subarray with equal 0s and 1s" problem. This reduces the time complexity from O(n²) to O(n).

The key insight: when `vowelCount - consonantCount` is the same at two positions i and j, the substring between them has equal vowels and consonants. We need to track these differences along with the product condition modulo k.
