## Improvement Intent

The original algorithm uses nested loops to check every substring, resulting in \(O(n^2)\) time complexity. This is improved to \(O(n)\) by:

- Treating vowels as +1 and consonants as –1, and computing a prefix difference.
- Observing that the condition `(vowelCount * consonantCount) % k == 0` simplifies to `vowelCount² % k == 0` because the counts are equal.
- Precomputing a modulus `L` such that a substring satisfies the condition iff `vowelCount % L == 0`.
- Using a hashmap to count previous prefixes with the same `(diff, vowelCount % L)`, so each substring that meets both criteria is counted in constant time.

This eliminates the nested loop, handling large inputs efficiently.
