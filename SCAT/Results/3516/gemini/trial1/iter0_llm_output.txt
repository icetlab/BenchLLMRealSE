The original code uses a lazy-computation approach with a nested `HashMap` to cache the sums of neighbors. While this avoids re-computation for the same cell, it incurs overhead from `HashMap` operations (hashing, boxing, potential collisions) and `computeIfAbsent` calls for every query.

The improved version switches to a pre-computation strategy. In the constructor, it calculates the adjacent and diagonal sums for all cells in the grid and stores them in a `int[][][]` array. This moves the computational cost to the initialization phase. Subsequent calls to `adjacentSum` and `diagonalSum` become simple, fast lookups in this pre-computed cache. This approach eliminates the runtime overhead of `HashMap`s and lazy computation, leading to significantly better performance, especially when many queries are made to the `NeighborSum` object.
