## Improvement Intent

The original code creates an `ArrayList` from the array, removes the first element, sorts the rest, and sums the first element with the two smallest remaining elements. This can be optimized by avoiding the overhead of creating a list and sorting. Instead, we can find the two smallest elements after the first element in a single pass through the array, which reduces time complexity from O(n log n) to O(n) and eliminates unnecessary object creation.
