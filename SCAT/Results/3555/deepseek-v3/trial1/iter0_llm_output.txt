## Improvement Intent

The current implementation uses a PriorityQueue with Pair objects, which creates significant overhead due to boxing/unboxing and object creation. The main performance improvements are:

1. **Replace Pair with primitive array** - Using `int[]` instead of `Pair<Integer, Integer>` eliminates object overhead
2. **Use custom comparator with primitive ints** - Avoids boxing/unboxing overhead in comparisons
3. **Reduce object creation** - The original creates a new Pair for each heap operation; we can reuse arrays
