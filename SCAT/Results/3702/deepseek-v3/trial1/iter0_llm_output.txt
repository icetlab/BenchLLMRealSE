The main performance bottleneck is the O(n³) time complexity from generating subarrays and recomputing product, GCD, and LCM from scratch for each subarray. I will optimize by using sliding window expansion: for each starting index, extend the end index while maintaining running product, GCD, and LCM incrementally. This reduces complexity to O(n²) and avoids array allocation.
