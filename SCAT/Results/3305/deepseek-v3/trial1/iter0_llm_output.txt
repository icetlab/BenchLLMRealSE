## Improvement Intent

The original code uses `List.of(char, char)` as HashMap keys, which creates unnecessary object allocations and increases memory overhead. The key insight is that we can encode the pair of characters (prefix char at position i, suffix char at position length-1-i) into a single integer using bit manipulation. This reduces memory allocation, improves cache locality, and speeds up hash lookups.
