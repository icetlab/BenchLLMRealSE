## Improvement Intent

The original code uses a while loop that repeatedly removes the last character from the longest string until all three strings are equal. This approach is inefficient because it modifies strings character by character. Instead, we can find the longest common prefix of all three strings directly, then calculate the minimum operations as the sum of the differences between each string's length and the common prefix length. This reduces time complexity from O(L²) to O(L) where L is the total length of strings.
