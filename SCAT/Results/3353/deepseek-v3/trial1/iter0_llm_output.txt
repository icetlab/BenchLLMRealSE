## Improvement Intent

The original code has several performance issues: it uses string concatenation in a loop (O(n²) due to immutability), creates unnecessary substrings, and has redundant loops. I'll optimize by:
1. Using `StringBuilder` for efficient string reversal
2. Combining the substring collection and checking in a single pass
3. Reducing memory allocations by checking substrings directly without creating a reversed string
