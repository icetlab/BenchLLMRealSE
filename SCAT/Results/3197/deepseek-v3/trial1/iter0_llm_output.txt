## Improvement Intent

The original code uses a greedy bit-by-bit approach with HashMap operations that can be optimized. The main improvements:
1. Replace `HashMap` with arrays for faster lookups since we're dealing with integer keys in a limited range
2. Use primitive arrays instead of boxing/unboxing with `Integer` objects
3. Reduce redundant operations by combining the min/max tracking into a single pass
