The original algorithm uses two `HashMap<Integer, Integer>` objects (`pref` and `pref2`) to store per-bit-prefix minimum and maximum values. This requires multiple hash lookups per element (contains, get, put) and two separate maps. By combining the min/max into a single `HashMap<Integer, int[]>` and using `compute` to update both in one map operation, we reduce hash lookups and memory overhead, improving runtime performance while preserving the correctness of the strong-pair XOR computation.
