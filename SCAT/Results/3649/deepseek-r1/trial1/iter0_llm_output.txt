The original code enumerates all permutations, which is O(n!). I replaced it with bitmask DP over subsets: `dp[mask]` stores the minimum time to process exactly the locks in `mask`, using the first `popcount(mask)` multipliers. This preserves the exact answer while reducing time complexity to O(n·2^n).
